# PenDown · 轻量 Windows 便签

[English](README.md) | 简体中文

PenDown 是一个便携的 Windows 桌面便签工具。便签正文保存为普通 UTF-8 `.txt`，颜色、字体等格式保存在同名 `.style.json`，不需要数据库，也不需要输入 Markdown 语法。

## 下载与运行

从 [Releases](https://github.com/1148118271/PenDown/releases) 下载 `PenDown-*-win64.zip`，解压后双击 `PenDown.exe`。

- 系统要求：Windows 10 / 11 x64
- 不需要安装，首次启动会在 exe 同级创建 `data` 文件夹
- 运行时库已随压缩包附带
- 程序没有代码签名，Windows SmartScreen 可能提示“已保护你的电脑”，选择“更多信息 → 仍要运行”
- 建议放在用户目录；放在 `Program Files` 下可能没有写入权限

## 快速上手

主窗口是窄长的便签布局，上方是工具栏，下方是多级分组树。

- 右键分组：新建子分组、新建便签、重命名、移动到分组、删除
- 右键空白处：在根目录新建分组或便签
- 便签可以放在根目录，也可以放进任意层级的分组
- `Del` 删除，`F2` 重命名分组 / 打开便签，`F5` 刷新
- `Ctrl+N` 新建便签，`Ctrl+Shift+N` 新建分组
- 齿轮图标打开设置

删除便签或分组会移到 Windows 回收站。删除分组会连同其中的子分组和便签一起移入回收站。

## 便签编辑

便签打开为独立窗口，可以脱离主窗口自由拖动。

- 正文就是最终显示效果，不需要输入 Markdown 语法
- 正文第一行自动作为便签标题和文件名；修改第一行后保存会自动重命名
- `Ctrl+S` 保存；关闭有未保存内容的便签会二次确认
- 编辑区左侧显示行号
- 关闭主窗口只会隐藏到系统托盘，已打开的便签窗口会保持打开

常用快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+S` | 保存 |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | 加粗 / 斜体 / 下划线 |
| `Ctrl+0` | 当前行恢复正文样式 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 替换 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做正文 |
| `Ctrl+A` | 全选 |

## 颜色、样式与字体

格式入口在便签标题栏：

- **颜色盘**：设置文字颜色或背景颜色，包含常用色和自定义 RGB
- **样式库**：加粗、斜体、下划线、删除线、字号增减、超链接、字体选择
- **清除样式**：恢复默认字体、字号、颜色、背景和链接
- **格式刷**：复制光标处格式，再选中目标文字并松开鼠标即可应用

使用方式：

- 选中文字后点击样式，立即应用到选区
- 没有选区时设置的颜色或字体，会应用到后续输入的文字
- 颜色盘和样式库是浮动窗口，可以同时打开，也可以拖到编辑窗口外
- 超链接需要先选中文字，再输入网址；按住 `Ctrl` 点击链接会用系统浏览器打开
- `Ctrl+Z` / `Ctrl+Y` 当前只撤销/重做正文，样式和链接操作本身不进入撤销栈

这是纯文本 + 字符样式编辑器，不支持内嵌图片、表格和 Markdown 语法高亮。

## 界面语言

在设置顶部选择语言：

- **跟随系统**：中文系统显示中文，其他系统显示英文
- **中文**
- **English**

切换后需要重启 PenDown 生效。语言只影响界面文案，磁盘上的便签文件名和默认标题保持不变。

## 数据与备份

默认数据目录是 exe 同级的 `data`：

```text
PenDown/
├─ PenDown.exe
└─ data/
   ├─ 购物清单.txt
   ├─ 购物清单.txt.style.json
   └─ 工作/
      ├─ 周会纪要.txt
      └─ 项目 A/
         └─ 接口联调记录.txt
```

- 一个文件夹就是一个分组，`.txt` 文件就是一条便签
- 颜色、字体、链接等格式保存在同名的 `.txt.style.json`
- 已保存过的便签在编辑停止数秒后会自动保存；下次打开时如果发现自动保存内容，会询问是否恢复
- 设置 →“数据存储”可以更换数据目录；可以选择把现有便签复制到新目录，旧目录会保留
- 启动参数 `--data <目录>` 可以临时指定其他数据目录
- 升级程序时只替换 exe、DLL、`icons/` 和 `lang/`，不要覆盖或删除 `data/`
- 建议升级前备份整个 `data` 文件夹

## Git 同步（可选）

普通使用不需要 Git。需要多设备同步时：

1. 安装 [Git for Windows](https://git-scm.com/download/win)
2. 打开设置 →“Git 同步”
3. 填写仓库地址、分支，以及可选的用户名和密码/令牌
4. 关闭所有便签窗口
5. 点击“推送”或“拉取”

同步规则：

- 整个 `data` 目录作为一个 Git 仓库
- 推送：提交本地改动后强制推送，远程以本地为准
- 拉取：先把本地数据备份到 `%LOCALAPPDATA%\PenDown\backups`，再用远程内容强制覆盖本地
- 不做冲突合并
- 访问令牌使用 Windows DPAPI 加密后保存在本机

## 托盘与全局快捷键

关闭主窗口不会退出程序，而是隐藏到系统托盘；托盘菜单里的“关闭”才会真正退出。

默认全局快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+H` | 显示主窗口 |
| `Ctrl+Alt+N` | 新建便签 |

可以在设置 →“快捷键”中修改。新建便签的快捷键只打开编辑窗口，不会把主窗口从托盘带出来。

## 常见问题

### 删除的便签可以恢复吗？

可以。便签和分组会移到 Windows 回收站，打开回收站即可还原。如果数据目录位于网络驱动器等没有回收站的位置，删除会失败并提示，请改用资源管理器手动处理。

### 旧版 `.md` / `.wxr` 便签去哪了？

旧文件仍保留在数据目录中，不会被删除，但不会显示在便签列表里。请手动把内容转入新建的 `.txt` 便签。

### 可以同时开多个 PenDown 吗？

不可以。重复启动会唤醒已有实例，不会启动第二个进程。

### Git 同步提示找不到 git.exe

安装 Git for Windows，或者在设置 →“Git 同步”→“Git 程序”中填写 `git.exe` 的实际路径。

### 更新程序会覆盖便签吗？

不会。只替换程序文件即可，但不要覆盖或删除 `data` 文件夹。

### 为什么没有安装包？

PenDown 是便携程序，解压即用。如果放在 `Program Files` 下遇到写入权限问题，请改放到用户目录，或用 `--data` 指定单独的数据目录。
